Hola, mi nombre es Camilo Gaviria, este proyecto es personal de manera unica para ayudar en los negocios que mi padre le dejo a mi madre, llevar un control en estos, sirve para negocios a los que les entra dinero diario especificamente de busetas, hoy en dia la empresa a filiada de la buseta que tenemos entrega el dinero neto a los conductores, esto es un problema ya que muchas veces recibimos menos dinero, no podemos llevar un orden, tampoco queremos llevarlo de manera antigua a papel y lapiz y decidimos pasar a la tecnologia e ire narrando el proceso

Para este proyecto se decidio trabajar con tecnologias en lo psible gratuitas

- FrontEnd y BackEnd se decidio usar NextJS
- Base de Datos Firebase Storage y Authentication
- Dominio y Hosting con Vercel
- Envio de Correos con Resend
- Almacenamiento de imagenes con Cloudinary

Bibliotecas:
- lucide react
- firebase

## Scripts de Administración

El proyecto incluye scripts para tareas administrativas, como la creación de usuarios con rol de administrador:

- `npm run create-admin`: Crea un nuevo usuario administrador en Firebase

Para más información sobre cómo usar estos scripts, consulta [scripts/README.md](scripts/README.md).
